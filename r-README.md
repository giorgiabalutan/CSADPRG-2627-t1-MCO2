# CSADPRG - Milestone 1: Banking and Currency App (Java)

*Author: BALUTAN, Giorgia*

This is the R component of CSADPRG MCO1, a Banking and Currency App.

## How to Compile

### Pre-requisites

- R 4.x (alternatively, RStudio)
- [readr](https://readr.tidyverse.org/)
- [dplyr](https://dplyr.tidyverse.org/)
- [knitr](https://yihui.org/knitr/)

### Manual Compilation

1. Open R in this folder (`./R`)
2. In the R console, run:

```r
setwd("path/to/[CSADPRG] Milestone 1/R")   # the R folder
source("main.R")
```
